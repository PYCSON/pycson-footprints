# V430PV LIVE UI Future Layout Zoning Plan

Core principle: 整理，不是取消. Organize, do not remove. Functionality and recognizable cockpit identity stay first; visual cleanup is second.

## Top Bar
- Preserve Mother identity, current status, latest/version summary, theme/color controls, and safety mode.
- Keep the STEAM MATURE LOOP entry visible or pin it in an equivalent protected route-entry spot.
- Do not compress the top bar until theme/color controls have a protected container.

## Left Column
- Route Directory is the primary orientation structure.
- Module navigation and route groups should live below Route Directory.
- Legacy organ navigation can become an accordion only if all entries remain accessible.

## Center Main
- Current active route is the dominant panel.
- Steam Mature Loop readonly status and V430PT manual refresh status should live here as the active route when Steam is selected.
- Future EV radar/analyzer can be a placeholder or tab, but cannot imply official/trusted EV readiness without authorization.

## Right Column
- Review-required status, risk panel, AI command, notifications, proof/latest/report quick links.
- Risk/Replay/EV reference modules can be compact cards, not floating blockers.
- Right column should be lighter than the current accumulated black-area shell.

## Bottom Dock
- Safety buttons, launch/recheck buttons, rollback/proof/log quick access.
- Buttons must remain clearly readonly unless separately authorized.

## Protected Elements
- Mother identity, theme/color controls, Steam Mature Loop button, Steam Mature Loop module, Route Directory, and existing accessible modules must remain visible or clearly accessible.
