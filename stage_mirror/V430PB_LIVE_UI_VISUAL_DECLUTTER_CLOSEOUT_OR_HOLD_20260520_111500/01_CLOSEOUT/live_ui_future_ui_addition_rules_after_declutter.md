# Future UI addition rules after declutter

1. Add future routes through route families, not random always-visible cards.
2. Every route needs a left directory entry, center selected-route panel, right risk/boundary context, and bottom safe-action policy.
3. Preserve mother UI unless a separate mother UI authorization exists.
4. Patch LIVE UI only after backup and rollback plan.
5. Do not delete legacy modules in the first pass; contain, collapse, or relocate them.
6. Never add BUY_NOW, TRADEUP_NOW, trade/order, hidden DATA_BRIDGE write, hidden active payload write, hidden fetch, or hidden EV calculation.
7. Steam Mature Loop remains the accepted reference route for readonly route visibility, navigation, and boundary display.
